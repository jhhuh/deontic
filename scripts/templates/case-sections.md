# Case Section Labels (for translation)

These are the per-case section headings and table headers used by assemble-cases.py.

## Section Headings
- "Case {n}" → case heading prefix
- "Identity" → identity section
- "Fact Translation" → fact translation section
- "Judgment Comparison" → judgment comparison section

## Table Headers
- identity_grid: "ID", "Role", "Haskell"
- facts_grid: "Recognized Facts", "Haskell Encoding"
- judgment_grid: court name (dynamic), "Framework Output"
